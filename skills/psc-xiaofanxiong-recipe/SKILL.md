# 小饭熊的厨房 · 小红书美食笔记

生成可复用的“小饭熊的厨房”内容包，适用于单个菜品或批量菜品。
保持系列风格稳定：温暖的手账拼贴风、IP形象可见、中文排版清晰易读、充满家常美食的食欲感。

## 概述

默认生成文字内容（菜品简报 + 标题 + 文案 + 顺口溜 + 话题标签），浏览器出图为可选模式。

## 工作流程

1. 解析需求
2. 构建菜品结构化简报
3. 生成笔记文案包（默认输出）
4. 仅在用户明确要求时执行浏览器出图

## 解析需求

提取或确认：

- `菜品名称`
- 用户只要提示词、只要文案、还是要完整产出
- 用户是否明确要求浏览器出图

如用户省略次要字段，根据常见烹饪知识推断并在工作笔记中标注。不要因次要信息的缺失而中断流程。

## 构建菜品结构化简报

出文案前，先准备一份简报，覆盖以下内容：

- 中文菜名
- 英文菜名
- 一句卖点副标题
- 难度标签
- 准备时间
- 烹饪时间
- 人数
- 3-4 种主要食材及用量
- 3-4 种调味料
- 3-4 个味道/口感特点
- 4-6 个烹饪步骤
- 2-3 个小饭熊提醒
- 2-3 个成功关键
- 营养成分及估算热量
- 日常搭配建议
- 3-4 个衍生菜品
- 一句温暖结尾语

参考 [references/field-checklist.md](references/field-checklist.md) 确保字段完整。

## 生成笔记文案

为每个菜品产出以下内容。参考 [references/copy-sop.md](references/copy-sop.md)。

默认输出：

- 4-5 个标题选项（每条 20 字以内）
- 3 个开头文案选项
- 2 首四句顺口溜
- 1 组话题标签

风格：温暖、亲切、略带俏皮，让“小饭熊”的 IP 感贯穿全文。

## 出图模式（可选）

仅在用户明确要求生成图片、执行浏览器出图、或需要图文完整产出时进入此模式。

### 出图目标

固定使用 ChatGPT 项目页面：`https://chatgpt.com/g/g-p-69e87631526081919fe8f5728855cc4f-zi-mei-ti/project`

### 图像生成工作流

准备 3 页图（除非用户指定其他数量）：

- 第 1 页：封面
- 第 2 页：烹饪过程
- 第 3 页：营养与衍生菜品

应用 [references/image-sop.md](references/image-sop.md) 中的完整视觉体系。保持系列风格强于菜品个性变化。

### 浏览器执行步骤

使用 `playwright-cli` skill 执行浏览器操作：

1. 打开固定 ChatGPT 项目页面
2. 先准备好完整的第 1/2/3 页提示词，不要压缩或缩短
3. 可使用 `assets/` 中的参考图（如 mascot 形象 `master.png`、难度贴纸等）作为上传参考
4. 始终开启新对话，不要复用旧线程
5. 输入长中文提示词前，先复制到剪贴板再粘贴，避免中文乱码
6. 确认完整消息出现在对话中后提交
7. 记录生成的对话 URL
8. 等待图片生成完成后下载，按 `菜品名-01-cover`、`菜品名-02-process`、`菜品名-03-nutrition` 命名
9. 将下载的图片保存到对应菜品的本地文件夹

## 输出顺序

除非用户指定其他格式，按以下顺序输出：

1. 菜品结构化简报
2. 标题选项
3. 开头文案选项
4. 顺口溜选项
5. 话题标签

如执行了浏览器出图，追加：

6. 浏览器执行记录（含对话 URL）
7. 下载的图片文件路径

默认不输出 3 页图像提示词，仅在用户明确要求时才展示。
